# It's Over Time
A video game that mildly dislikes you.


This was designed for the TGC Game Jam 2026 with the themes Comic, Twist and Light. We were quite liberal in our interpretation(s) of these. The game itself is inspired in large part by the Stanley Parable, Disco Elysium and There Is No Game.

-----

Any hurt feelings when playing this game are mostly unintended and are slightly regretted. No office workers were harmed in the making of this game.
